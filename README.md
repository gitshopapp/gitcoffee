# GitCoffee ☕️💻

**Buy fresh roasted coffee directly from GitHub.**

GitCoffee is a real coffee shop and the first live storefront powered by **GitShop**.
Place an order in GitHub Issues, pay through secure Stripe Checkout, and track the process in the open.
Yes, coffee commerce in a repo is real. 🚀

## 🛒 How to Order

1. Go to the **Issues** tab in this repo.
2. Click **New issue** and choose the GitCoffee order template.
3. Fill in your order details and submit.
4. Pay using the secure **Stripe Checkout** link posted on your issue.
5. I roast your coffee to order and ship it within **1–2 days**.

## 🛍️ About GitShop

I’m building **GitShop** so anyone can sell anything on GitHub by turning a repo into a storefront.
GitCoffee is the first live store in that mission.

## 🎯 Blend Philosophy

Every **GITBLEND** version is designed to work beautifully for both espresso and drip-based drinks.
Roast style stays in the **light to medium** range, while origins may evolve between versions.
